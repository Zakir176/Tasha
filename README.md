# 🌸 Tasha — 14 Days of Love & More

**Tasha** is a curated collection of lightweight, love-themed web projects built with **plain HTML, CSS, and JavaScript**.  
The repository hosts the **14 Days of Love** challenge (a 2-week series of mini apps for couples), plus additional related projects. Each mini project is intentionally small and daily-buildable so you can iterate fast, push daily commits, and keep a GitHub streak.

---

## ✨ What this repo delivers
- 14 standalone mini web apps (one per day) that are easy to complete and deploy.
- A **Love Portal** (Day 14) that acts as the central hub linking all projects.
- A **unified visual identity** via shared CSS variables for consistent styling across projects.
- Simple data persistence using `localStorage` (no backend required).
- GitHub Pages-ready structure for easy publishing.

---

## 📅 14 Days of Love — The Projects
Each project below is purposely scoped to be achievable in a single day.

1. **Virtual Bouquet** — click to bloom flowers on screen.  
2. **Yes/No Proposal Page** — interactive “Will you be mine?” UX.  
3. **Secret Message Encoder** — ROT13 / Base64 love note obfuscator.  
4. **Love Notes Sticky Wall** — add sticky notes to a digital wall.  
5. **Memory Jar** — add and revisit daily memories.  
6. **Virtual "I Love You" Jar** — open a daily surprise note.  
7. **Daily Love Challenge** — daily tasks with progress tracking.  
8. **Relationship Milestone Tracker** — save dates, photos, and notes.  
9. **Memory Timeline** — vertical timeline for relationship events.  
10. **Love Story Timeline** — scrapbook-style visual story.  
11. **Virtual Scrapbook** — templates for photos, videos, and notes.  
12. **Couple’s Bucket List** — add/share and mark items completed.  
13. **365 Days of Love Challenges** — large dataset of ideas for long-term use.  
14. **Love Portal (Final Hub)** — central index linking all projects.

## 🚀 Deployment

This repo is **GitHub Pages friendly**.  
Once published, projects can be accessed like so:

- Main Portal → `username.github.io/Tasha/projects/love-portal/`  
- Individual Day → `username.github.io/Tasha/projects/day1-virtual-bouquet/`
